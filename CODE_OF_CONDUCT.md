## Code of Conduct

This project is maintained as a **professional, high‑quality codebase**. All contributors and participants are expected to behave in a way that reflects that standard.

The goal of this Code of Conduct is to ensure a respectful, safe, and productive environment for everyone involved.

---

## 1. Expected Behavior

All participants are expected to:

- **Be respectful and professional**
  - Use clear, polite, and technical language in discussions.  
  - Critique ideas, not people.  
  - Assume good faith, but provide honest, constructive feedback.

- **Stay on-topic and focused**
  - Keep issues and pull requests focused on the problem at hand.  
  - Avoid off-topic debates, personal conversations, or non-technical arguments in project channels.

- **Maintain a high quality bar**
  - Strive for clean, readable, and maintainable code.  
  - Follow the project’s architecture and guidelines.  
  - Avoid “quick hacks” that compromise long‑term quality.

- **Collaborate openly**
  - Share reasoning behind decisions.  
  - Be willing to revise or abandon an approach if a better one is proposed.  
  - Respect review feedback and iterate when requested.

---

## 2. Unacceptable Behavior

The following behaviors are not acceptable under any circumstances:

- **Harassment or abuse**
  - Personal attacks, insults, or derogatory comments.  
  - Discriminatory language or behavior based on race, gender, religion, nationality, disability, or any other personal characteristic.

- **Unprofessional communication**
  - Aggressive, sarcastic, or hostile responses in issues or reviews.  
  - Public shaming of individuals or contributors.

- **Disrespecting project boundaries**
  - Ignoring clearly stated contribution guidelines.  
  - Repeatedly submitting large structural changes or refactors against explicit guidance.  
  - Introducing code or dependencies that are clearly outside the scope of the project.

- **Dishonesty or misrepresentation**
  - Claiming others’ work as your own.  
  - Submitting code you do not have the right to share.  
  - Intentionally hiding security issues or vulnerabilities for personal gain.

---

## 3. Scope

This Code of Conduct applies to:

- All interactions related to the project, including:  
  - Issues, pull requests, code review comments, and discussions.  
  - Project‑related conversations in any public or private channels hosted by the maintainer.

- All contributors, maintainers, and any third parties interacting with the project.

---

## 4. Enforcement

The project maintainer may take any of the following actions in response to unacceptable behavior:

- A private or public **warning**.  
- **Requesting changes** before a pull request can be considered.  
- **Closing or rejecting** issues or pull requests.  
- **Temporary or permanent ban** from contributing to the project, at the maintainer’s discretion.

Decisions are made with the goal of protecting:

- The **stability and quality** of the codebase.  
- The **professional tone** of the project.  
- The **time and focus** of the maintainer and serious contributors.

---

## 5. Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct, you can report it directly to the maintainer.

When reporting, please include:

- A clear description of the incident.  
- Links or references (issue numbers, PRs, screenshots) where possible.  
- Any additional context that may help understand the situation.

Reports will be reviewed in good faith, and appropriate action will be taken at the maintainer’s discretion.

---

## 6. Final Notes

This project aims to maintain a **serious, professional, and high‑quality standard**. Participation here is a privilege, not a right.

By interacting with this repository, you agree to:

- Follow this Code of Conduct.  
- Respect the maintainer’s decisions.  
- Contribute in a way that improves the project technically and professionally.
